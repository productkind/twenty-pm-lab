# Twenty PM lab

Your own copy of Twenty, a real open-source CRM, to investigate, break and fix in Little Parrot's technical skills learning path for product managers. It runs in GitHub Codespaces, in your browser, so nothing gets installed on your laptop.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/productkind/twenty-pm-lab?quickstart=1)

## Start here

1. Sign in to GitHub and click **Open in GitHub Codespaces** above.
2. Wait until the terminal says **Setup is finished**. The first time, your codespace installs everything the app needs, which takes several minutes.
3. In the terminal, type `start-app` and press Enter. Wait until it says **Twenty is ready**.
4. Open a second terminal with the **+**, type `load-story` and press Enter. You only need to do this once.
5. Open a third terminal, type `start-frontend` and press Enter.
6. In the **Ports** tab, open port 3001 and sign in.

## What's in this copy

- Twenty v2.48.0, made by [Twenty.com, PBC](https://twenty.com). Twenty's own README is in [README.twenty.md](README.twenty.md).
